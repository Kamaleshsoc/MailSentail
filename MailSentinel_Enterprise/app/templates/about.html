MAILSENTINEL / PLATFORM

Detection Method & Platform Scope

Understand what the current MailSentinel engine does and does not verify.

Current inspection capabilities

  • Parse raw .eml and .txt email source, including common headers and MIME message bodies.
  • Compare From, Reply-To and Return-Path domains.
  • Read SPF, DKIM and DMARC statuses reported in the supplied Authentication-Results header.
  • Extract URLs and flag selected patterns such as raw IP addresses, known shorteners and punycode host labels.
  • Identify selected urgency, credential and payment manipulation phrases.
  • Review attachment filenames and flag selected risky file extensions.
  • Store scan evidence and provide investigation history and response recommendations.
Important: not a live enterprise mail security gateway

MailSentinel currently performs local, rule-based static analysis. It does not connect to Microsoft 365, Google Workspace, Proofpoint, mail gateways, EDR, SIEM, threat intelligence feeds or sandbox infrastructure. It does not independently validate DNS authentication, open URLs, detonate attachments or run a trained machine-learning model. Dashboard totals represent only local scans saved in this database.
